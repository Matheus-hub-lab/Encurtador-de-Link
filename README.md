# 🔗 Encurtador de Links

Um projeto simples de **Encurtador de Links** desenvolvido utilizando **HTML, CSS e JavaScript**, com o objetivo de praticar conceitos fundamentais de desenvolvimento web, manipulação do DOM e criação de interfaces modernas.

A aplicação permite que o usuário insira um link longo e obtenha uma versão encurtada para facilitar o compartilhamento.

---

## 🚀 Demonstração

Interface simples e intuitiva onde o usuário:

1. Cola um link no campo de entrada
2. Clica no botão **Encurtar**
3. Recebe um link reduzido para compartilhamento

---

## 🖥️ Tecnologias Utilizadas

- **HTML5** – Estrutura da aplicação  
- **CSS3** – Estilização e layout moderno com gradiente  
- **JavaScript** – Lógica da aplicação e manipulação do DOM  

---

## 🎯 Objetivos do Projeto

Este projeto foi desenvolvido para praticar:

- Estruturação de páginas com **HTML**
- Estilização e layout responsivo com **CSS**
- Manipulação de elementos usando **JavaScript**
- Eventos de clique e interação do usuário
- Criação de interfaces simples e funcionais
